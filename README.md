# Git Collab Lab

This repository is a 14-day Git collaboration training lab.

Goal: become comfortable with normal team workflows, conflict resolution, rebase, history cleanup, and common recovery scenarios.

## How To Use This Lab

Each session follows the same loop:

1. Read the task card in `docs/exercises`.
2. Say the current repository state before running risky commands.
3. Complete the scenario using Git from the command line.
4. Record what happened in `docs/logs`.
5. If something broke, add an incident note in `docs/incidents`.

## Training Rules

- Prefer command line Git. GUI tools are allowed for inspection.
- Before merge, rebase, reset, clean, or force push, pause and explain the state.
- Commit messages use English.
- Reflections and incident notes can use Chinese.
- Use GitHub for practice, but compare key steps with GitLab in `docs/reference/github-gitlab-map.md`.

## Tiny App

The `src` folder contains a small browser app used for practice changes.

Open `src/index.html` directly in a browser to view it.
